# Deep Learning Assignment 1


## Environment

- Platform: [Kaggle](https://www.kaggle.com/)
- Accelerator: GPU T4 x2
- Dataset: [Fashion-MNIST](https://www.kaggle.com/datasets/zalando-research/fashionmnist)

## How to Reproduce

1. Open `DL-fashinMINST.ipynb` on Kaggle.
2. Under **Add Data**, attach the Fashion-MNIST dataset linked above.
3. Under **Settings**, set the accelerator to **GPU T4 x2**.
4. Run all cells from top to bottom, in order
5. Random seed `42` is set at the start of the notebook so all reported numbers should reproduce exactly on a rerun.


## Notes

- All plots include axis labels, titles, and legends as required.
- The test set is touched exactly once, in Part 7, after model selection was finalised.
